推荐配置： VS Code（编辑器） + Tex Live（编译引擎） + LaTeX Workshop（插件）

环境配置

安装本地 LaTeX 发行版

这里我推荐安装最新版的 texlive，可以直接去官网或者镜像站安装，大概有 5GB 大小，苹果用户可以直接安装 MacTeX。

MacTeX 和 TeX Live 实际上是相同的东西，只是名字不同，针对的平台也有所不同。

  1. TeX Live：

  • TeX Live 是一个跨平台的 TeX 发行版，可以在多种操作系统上运行，包括 macOS、Linux 和 Windows。

  • TeX Live 包含了 TeX 系统的核心组件，以及大量的宏包、字体和工具，可以用来排版各种类型的文档

  1. MacTeX：

  • MacTeX 是专门为 macOS 平台打包的 TeX 发行版。

  • MacTeX 实际上是 TeX Live 在 macOS 上的一个打包版本，它包含了 TeX Live 发行版以及一些额外的 macOS 上使用的工具和应用程序。

  • MacTeX 提供了一套完整的 TeX 环境，包括了 TeX Live 的所有功能，同时也包括了一些 macOS 下的编辑器、预览器和其他辅助工具，让用户可以更方便地使用 TeX 进行排版工作。

因此，从功能上来说，MacTeX 和 TeX Live 是一样的，只是针对的平台不同，以及在 macOS 上提供了一些额外的工具和应用程序。如果你是 macOS 用户，你可以选择安装 MacTeX，它提供了更完整的 TeX 使用环境和更友好的 macOS 集成。

配置 LaTeXworkshop

这里我是使用的 Mac 环境，所以配置的是 Mac 环境下的路径。如果使用 Windows 环境，请配置 Windows 环境下的路径。

以及由于我使用的是公司内的 CatPaw 编辑器，对于默认模式的 PDF 预览支持不是很好，所以我改成了用 legacy 这种老式预览面板，如果你的可以支持可以删掉这个

在插件中搜索 LaTeX Workshop，然后安装它。
